# Seguridad y manejo de información sensible

No subir credenciales, contraseñas, claves de API, tokens, direcciones de dispositivos identificables, consentimientos firmados ni información de participantes. Mantener configuración local fuera de Git y usar archivos `.example`.

Si se incorpora por error un secreto: revocarlo/cambiarlo **antes** de intentar borrarlo del historial. Una eliminación posterior no asegura que haya desaparecido de clones o respaldos.

Antes de cada cambio en hardware comprobar tensiones, polaridad, corriente y mecanismos de parada. Las notas del repositorio no sustituyen los ensayos de seguridad ni el protocolo aprobado.
