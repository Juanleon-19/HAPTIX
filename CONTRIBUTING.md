# Cómo aportar al repositorio

1. Crear una rama `docs/tema`, `feat/area` o `fix/area`.
2. Registrar el origen de cada archivo (fecha, revisión, SHA-256 y licencia).
3. No alterar datos experimentales brutos; procesarlos en scripts separados.
4. Adjuntar evidencia verificable antes de marcar una funcionalidad como probada.
5. No hacer commits con información personal o configuraciones de red reales.
6. Evitar abrir incidencias o PR con resultados de participantes identificables.

Las modificaciones de metodología deben concordar con el protocolo aprobado y el documento de tesis.
