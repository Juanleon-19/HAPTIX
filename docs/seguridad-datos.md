# Seguridad, ética y protección de datos

**El repositorio no es el lugar para:** consentimientos firmados, nombres de participantes, rostros sin autorización, datos de contacto, contraseñas Wi-Fi, tokens, registros con identificadores personales ni mediciones de salud individualizadas.

Las pruebas con personas deben disponer de consentimiento informado, procedimiento aprobado, criterios de parada y límites eléctricos/térmicos definidos. Los resultados publicados serán agregados o seudonimizados y revisados para evitar reidentificación.

En el hardware: validar protecciones inductivas y corrientes máximas; preservar la capacidad de desenergización; usar aislamiento mecánico y térmico; no aplicar un SMA no validado sobre piel.
