# Decisiones de alcance del repositorio

## DEC-001 — Identidad del proyecto (2026-11-21)

**Decisión:** nombre del repositorio **HAPTIX**. Propietario previsto: `Juanleon-19`. Rama principal `main`, visibilidad privada inicial. No se modifica el título académico de la tesis.

## DEC-002 — Tecnologías incluidas (2026-11-21)

**Decisión:** documentar exclusivamente las tecnologías **ERM**, **freno electromagnético por tendón y fleje** y **SMA/Nitinol**. La integración actual en la aplicación VR no debe atribuirse a todas las tecnologías: el SMA se estudia en banco.

## DEC-003 — Trazabilidad experimental

Separar los datos medidos, resultados de simulaciones, valores de catálogo y supuestos. No declarar la validación de una placa o script basándose únicamente en su presencia en Drive. Revisar la coherencia de cada par esquema/PCB/Gerber antes de publicar una versión marcada como funcional.

## DEC-004 — Publicación

GitHub almacena el código, documentación, fuentes CAD seleccionadas y resultados compactos; Drive conserva el conjunto completo de originales y datos de gran tamaño. Todo dato de participantes debe ser autorizado y anonimizado.
