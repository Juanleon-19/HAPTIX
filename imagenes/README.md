# Figuras, diagramas y fotografías

Conservar autoría y metadatos mínimos. Primero incluir imágenes propias ya aprobadas: arquitectura electrónica/VR/mecánica, prototipo real, CAD, PCB, oscilogramas y geometrías SMA. No añadir capturas sin permiso, figuras generadas con errores o fotos con participantes identificables.

Se recomienda `imagenes/arquitectura/`, `imagenes/electronica/`, `imagenes/mecanica/`, `imagenes/pruebas/`; registrar fuente en el pie de figura y revisión.
