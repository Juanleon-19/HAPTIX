# ERM: simulación eléctrica

Se incorpora `matlab/Generar_Figuras_ERM_LTspice.m` y `README_ORIGEN.md` desde Drive. Las fuentes originales describen procesamiento de simulaciones con un modelo ilustrativo; **la resistencia, inductancia y respuesta mecánica del motor requieren medición**.
